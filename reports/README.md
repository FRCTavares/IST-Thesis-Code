# Generated Reports

This folder contains generated analysis outputs from local experiments, reruns,
visual validation, timing analysis, tracking evaluation, and temporary debugging.

The contents of this folder are intentionally not tracked by Git by default.
Only this README is tracked.

Use this folder for:

- timing reports
- tracking reports
- visual validation outputs
- replay/evaluation summaries
- temporary diagnostic runs
- generated videos, plots, CSVs, and markdown summaries

Do not treat this folder as thesis documentation.

Curated results that are important for the thesis should be copied or rewritten
into `docs/results/`, where they can be tracked, reviewed, and cited.
