## 5. Priority E - Write TIM-V1 Design, Not Full Code Yet

### Objective

Prepare the next novelty step using the latent-world inspiration without expanding the thesis scope too much.

### TIM-V1 Should Not Be

```text
full UAV latent world model
global ReID system
DeepSORT replacement
large foundation model
language-conditioned navigation model
```

### TIM-V1 Should Be

```text
target-only lightweight latent appearance memory
```

### Proposed TIM-V1 Pipeline

```text
selected target crop
    -> tiny encoder
    -> compact latent vector z_t
    -> target memory update
    -> candidate latent similarity during ambiguity/loss
```

### TIM-V1 Score

Extend the TIM-V0 score:

```text
S_j = w_iou S_iou
    + w_dist S_dist
    + w_scale S_scale
    + w_conf S_conf
    + w_id S_id
    + w_lat S_lat
    - w_amb S_amb
```

Where:

```text
S_lat = cosine_similarity(z_memory, z_candidate)
```

or:

```text
S_lat = exp(-||z_memory - z_candidate||_2)
```

### Latent Memory Update Policy

```text
LOCKED:
    update latent memory slowly

UNCERTAIN:
    use latent memory, but do not update it

LOST:
    use latent memory for reacquisition, do not update it

REACQUIRED:
    update only after confirmation

NO_TARGET:
    no memory
```

This prevents memory corruption from a wrong candidate.

### Suggested Document

Create:

```text
docs/Novelty/TIM_V1_LATENT_TARGET_MEMORY_PLAN.md
```

### Done When

