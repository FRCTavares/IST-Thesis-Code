# Documentation archive

This directory contains tracked historical material that remains useful for
traceability but is not current thesis authority.

## Contents

- `results/` — superseded algorithm-version and comparison interpretations.
- `data_catalogue_cleanup/` — historical bag and artefact cleanup records.

## Use restrictions

Archived documents may explain how the project evolved, but their method
descriptions, thresholds, result values, and claim language must not override:

- the current implementation;
- the canonical runtime configuration;
- `docs/research_question.md`;
- `docs/NOVELTY.md`;
- `docs/algorithm/tim_mars_versions.md`;
- `docs/algorithm/tim_mars_evidence_versions.md`;
- promoted current evidence under `docs/results/`.

Historical paths and names are retained where changing them would weaken
provenance.
