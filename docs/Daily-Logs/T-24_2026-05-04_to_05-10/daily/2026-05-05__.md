## TIM-V0 Selected-Target Memory

Implemented and tested TIM-V0, a selected-target memory layer above tracker outputs.

Validation completed:
- Synthetic unit tests: 12/12 passing.
- ROS node publishes `/target_memory` and `/target_memory/status`.
- TIM mirrors dashboard `/target` selection.
- TIM topics are recorded in video bags.
- Live occlusion bag recorded and analysed.

Evidence bags:
- `2026-05-05__09-55-39__video__tim_v0_occlusion_01`
- `2026-05-05__10-07-32__video__tim_v0_id_switch_02`

Key results:
- Live occlusion state sequence: `LOCKED -> UNCERTAIN -> REACQUIRED -> LOCKED`.
- Longer loss sequence: `LOCKED -> UNCERTAIN -> LOST -> REACQUIRED -> LOCKED`.
- TIM-V0 overhead on `tim_v0_occlusion_01`:
  - mean: 0.1174 ms
  - p95: 0.2046 ms
  - p99: 0.8148 ms

Deterministic injected ID-switch result:
- Original selected ID: 1
- Injected replacement ID: 3
- Gap: 2.0 s
- Raw ID selector valid after fault: 0/110
- TIM-V0 valid after fault: 85/110
- TIM reacquired ID 3 after 0.01 s
- Reacquisition quality: 0.825

Conclusion:
TIM-V0 provides repeatable evidence that selected-target memory can recover from tracker ID reassignment where a raw selected-ID target selector fails.
