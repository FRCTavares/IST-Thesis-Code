## TIM-V0 Evaluation Consolidation and TIM-V1A Preparation

## 1. Main Goal

Strengthen the thesis evidence around TIM-V0 before starting TIM-V1 implementation.

Today is focused on evaluation credibility, not new features. The main objective is to improve selected-target correctness evaluation so that TIM-V0 becomes a solid thesis baseline and TIM-V1 has a clear motivation.

Core thesis direction:

Maintain one operator-selected person as a control-valid target for RGB-only onboard micro-UAV following under bounded latency and noisy detector-tracker outputs.

---

## 2. Starting Context

### 2.1 TIM-V0 status

TIM-V0 is frozen as the geometry-only selected-target memory baseline.

Frozen features:

- selected-target memory above tracker outputs
- raw /target mirroring
- IoU, centre-distance, scale, confidence, same-ID bonus, and ambiguity penalty
- explicit states: NO_TARGET, LOCKED, UNCERTAIN, LOST, REACQUIRED
- control modes: NO_CONTROL, NORMAL, YAW_ONLY, HOVER, CONFIRM
- /target_memory
- /target_memory/status
- live-stack flags: --target-memory and --no-target-memory
- deterministic ID-switch fault-injection evaluation
- threshold sensitivity sweep

### 2.2 TIM-V0 evidence so far

Synthetic tests passed: 12 passed.

Representative TIM-V0 latency:

- p95 usually below 0.3 ms in tested bags
- overhead is negligible compared with detector and tracker latency

Deterministic ID-switch fault-injection result:

- raw selected-ID baseline failed after injected ID switch
- TIM-V0 reacquired in 13/15 cases
- mean validity gain: 0.635
- mean reacquisition time: 0.400 s

Threshold sweep interpretation:

- lower accept_score_lost gives more reacquisitions
- higher accept_score_lost is safer but more conservative
- default accept_score_lost = 0.60 is a conservative safety-oriented V0 default

## 3. Evaluation Upgrade

Supervisor feedback made the key evaluation issue clear:

Correct target is more important than any target.

Valid target duration is not sufficient. A target output is useful for UAV following only if it corresponds to the selected physical person.

The evaluation must separate:

- correct selected-target duration
- wrong-target duration
- lost duration while the selected target is visible
- safe invalid duration when the selected target is not visible

Current objective:

Increase correct-target duration while keeping wrong-target duration near zero.

## 5. TIM-V1 Direction

TIM-V1 should add a lightweight target-only appearance cue.

TIM-V1 should not become:

- full UAV latent world model
- global ReID system
- DeepSORT replacement
- detector retraining project
- language-conditioned navigation model

Recommended implementation order:

1. TIM-V1A: colour / HSV target memory baseline
2. TIM-V1B: tiny learned embedding only after V1A and evaluation are clean

### 11.6 TIM-V1A design document created

Created:

- docs/Novelty/TIM_V1A_COLOUR_TARGET_MEMORY.md

Purpose:

- define the first appearance-memory step after TIM-V0
- keep TIM-V1A training-free and interpretable
- avoid jumping directly to learned embeddings before the field dataset exists

Decision:

- TIM-V1A will use HSV colour histograms with upper/lower body split
- appearance will be used selectively during ambiguity, uncertainty, or loss
- memory updates must remain conservative to avoid memory corruption
