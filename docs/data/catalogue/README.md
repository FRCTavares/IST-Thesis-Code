# Data Catalogue

This folder contains the active metadata used to understand and locate thesis bag data.

Active files:

- `bag_layout.md`: human-readable explanation of the bag folder taxonomy.
- `bag_inventory.md`: readable table of known useful/canonical bags.
- `bag_inventory.yaml`: machine-readable bag inventory.
- `tim_eval_catalogue.yaml`: TIM evaluation catalogue used by tooling and review workflows.

Archived files:

- `archive_legacy_cleanup/`: historical migration manifests from previous bag reorganisations. These are kept for traceability but are not part of the active catalogue.
