# P031 parameter-sensitivity development evidence

Status: promoted development evidence; not held out

## Purpose

This package holds the tracked, byte-for-byte-copied provenance and
aggregate artifacts backing
[`../p031_parameter_sensitivity_summary.md`](../p031_parameter_sensitivity_summary.md).
It does not rerun the experiment, alter the matrix, or replace the frozen
protocol document.

The originating generated report path is
`reports/p031_parameter_sensitivity_5b340c2b_2026-08-08/`, which is
git-ignored generated output, regenerable from the tracked scripts below
against the frozen manifest, canonical config, and existing capture/replay
bags.

## Copied artifacts

- `parameter_sensitivity_lock.json` -- materialized-configuration lock
  (canonical config hash, manifest hash, all 29 configuration hashes,
  repository commit/branch/dirty state at materialization time).
- `run_provenance_final_invocation_dev_june_seq04.json` -- provenance from
  the final `--run` invocation. This file is overwritten by each `--run`
  invocation of the frozen tool, so it reflects only the last sequence
  (`dev_june_seq04`); it is not the sole record of execution.
- `batch{1,2,3,4}_dev_{may_hard_reentry,june_seq01,june_seq03,june_seq04}.log`
  -- the complete stdout/stderr of each of the four per-sequence batch
  invocations, including the one failed-then-corrected `dev_june_seq01`
  attempt's traceback, preserved rather than discarded.
- `matrix_all_sequences.{csv,json}` -- all 116 cells, one row per
  (sequence, configuration).
- `matrix_aggregate.{csv,json}` -- 29 rows, one per configuration, durations
  summed across all 4 development sequences.
- `dimension_tradeoff.{csv,json}` -- the aggregate table reshaped and sorted
  by true parameter value per dimension (canonical inserted in its correct
  monotonic position, not positionally first).
- `SHA256SUMS` -- hashes of every file in this directory.

The two figures referenced in the main summary
(`p031_all_dimensions_wrong_lost.png`, `p031_confirmation_time_tradeoff.png`,
generated by `tools/analysis/plot_parameter_sensitivity.py` from
`matrix_aggregate.csv` only) are git-ignored generated output, same as
P030's bbox-size figures, and are not duplicated into version control; they
live under
`reports/p031_parameter_sensitivity_5b340c2b_2026-08-08/aggregate/figures/`.
