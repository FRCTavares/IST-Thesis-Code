# Artifacts

Generated experiment outputs live here.

Typical subfolders:

- `bags/`: ROS 2 bags and replay outputs.
- `reports/`: timing, tracking, and comparison reports.
- `figures/`: generated plots and exported figures.
- `videos/`: rendered overlay videos.
- `logs/`: non-ROS generated logs.

Large or generated files in this folder are intentionally not tracked by Git.
