# tools/flight

Last reviewed: 2026-09-17

## Purpose

Flight-readiness and field-preflight helpers used from the Raspberry Pi before
physical aircraft operation.

## Contents

- `field_preflight_check.sh` validates the field-network and runtime prerequisites
  required by the current flight procedure.

## Authority

Operator sequencing and approved launch commands live in `docs/flight/README.md`.
This directory contains executable helpers, not an alternative operator runbook.
