# Bag annotation UI Tools

UI and video tools for inspecting TIM-MARS outputs.

Important scripts:

- `tim_clean_ui.py` — main cleaner TIM annotation/evaluation UI.
- `tim_clean_ui.py` — clean TIM-MARS visual inspection and annotation UI.
- `render_all_tracks_id_video.py` — renders tracker ID videos.
- `video.py` — shared bag annotation UI/video helper code.
- `tim_ui_discovery.py` — shared bag and annotation discovery for the current repository layout.
