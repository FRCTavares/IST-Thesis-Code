# Experiment Replay Tools

Reproducible replay runners.

Important scripts:

- `run_one_clean_tim_replay.sh` — replays an existing bag with detections/tracks and reruns TIM-MARS.
- `run_one_detector_tim_replay.sh` — reruns detector/tracker/TIM from image_raw source bags.
- `select_largest_track_id.py` — helper for selecting the largest visible track.
