# Analysis Tools

Offline analysis and evaluation scripts.

Important scripts:

- `evaluate_tim_target_correctness.py` — evaluates selected target correctness against manual annotations.
- `evaluate_tim_target_bbox_correctness.py` — evaluates bbox correctness.
- `extract_tim_all_scores.py` — extracts TIM-MARS diagnostic candidate scores from bag status messages.
- `analyse_bag_timing.py` — timing statistics for bags.
- `analyse_bag_tracking.py` — tracking statistics for bags.
- `check_live_timing_invariants.py` and `collect_live_timing_stats.py` — live timing validation helpers.
