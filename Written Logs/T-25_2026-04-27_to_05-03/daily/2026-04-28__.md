# Daily Plan - 2026-04-28 (Day 28) - Implementation Focus

## Context Carry-Over

  - Add an offline path to turn recorded bags into usable overlay videos for reports, debugging, and demo evidence.
  - Improve live operator usability by allowing target IDs to be inspected and selected directly from the `live-stack>` terminal prompt.

  - `start_live_stack.sh` had only a basic rosbag hook.

  - Terminal interaction only supported `status`, `clear`, and `stop`.
  - `tools/` was mixed, with launchers, analysis scripts, validation utilities, camera probes, setup scripts, and experiments all in the same folder.

  - Do not record `/camera/image_raw` during normal flight sessions because it is too heavy.
  - Keep the live perception and control stack lightweight.
  - Use `/camera/dashboard` as the recorded video stream.
  - Preserve MCAP bag format.
  - Keep generated bags and rendered videos out of Git.
  - Avoid breaking existing live-stack usage.
